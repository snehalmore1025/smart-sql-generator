# SmartSQLGenerator

A rule-based SQL code generator that converts natural language descriptions into SQL queries, simplifying database creation and management.

## Overview

SmartSQLGenerator is a standalone application designed to make SQL operations easier through algorithm-based parsing, keyword recognition, and automatic data type inference.

## Features

- Generate SQL queries from natural language input
- Automatically infer data types and constraints
- Create database tables dynamically
- Perform CRUD operations (Create, Read, Update, Delete)
- Preview and edit generated SQL queries
- Maintain SQL execution history

## Tech Stack

- **Database:** MySQL
- **Core Approach:** Algorithm-based parsing and rule-based logic

## Purpose

Built to simplify SQL query generation, reduce manual coding effort, and improve accessibility for users learning or working with databases.

## Status

Developed as an MCA mini project.
